# Data folder

The dataset files are included in this repo:

```
data/train.csv   (103,904 rows - used to train the models)
data/test.csv    (25,976 rows  - used to test the models)
```

Source: Airline Passenger Satisfaction dataset on Kaggle
https://www.kaggle.com/datasets/teejmahal20/airline-passenger-satisfaction

You do NOT need to download anything. `python train_models.py` reads
these two files directly, and the whole project depends on them.
